หมายเหตุเกี่ยวกับ Dataset
- เนื่องจากชุดข้อมูล CIFAR-10 เป็นชุดข้อมูลภาพ (Image Dataset) ที่ถูกจัดเตรียมไว้ในรูปแบบมาตรฐาน และสามารถ
  เรียกใช้งานได้โดยตรงผ่าน Keras API (เช่น keras.datasets.cifar10.load_data()) จึงไม่มีไฟล์ Feature 
  ในลักษณะตาราง (เช่น .csv หรือ .txt) ให้ใช้งานแยกต่างหาก
- ดังนั้น ใน Repository นี้จะ ไม่รวมไฟล์ Dataset ของ CIFAR-10 ไว้ภายในโปรเจค แต่จะใช้วิธีโหลดข้อมูลแบบ
  อัตโนมัติผ่านโค้ดแทน
- อย่างไรก็ตาม ได้มีการระบุขั้นตอนการเรียกใช้งาน CIFAR-10 ไว้อย่างชัดเจนภายในไฟล์ .ipynb เพื่อให้สามารถทำ
  ซ้ำ (reproduce) การทดลองได้อย่างครบถ้วน
